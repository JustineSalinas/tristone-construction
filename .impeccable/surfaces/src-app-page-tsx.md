## Direction contract

THESIS: Tristone builds Filipino homes, not SaaS dashboards — the page is a bahay-na-bato (ancestral Filipino house) rendered as a website, refusing the dark-card-grid contractor-site default this build already fell into.

OWN-WORLD: Deep molave-hardwood brown (#2a1d14-range) as the dominant ground; warm capiz-shell cream (#f3ead9-range) as the panel/content surface, with a soft pearl sheen, never flat white; wrought-iron near-black (#17120d) for rules, type, and linework; Tristone orange (sampled from the real logo) reserved as a single warm accent — a lit threshold, never a UI-chrome color. Headlines in a bold slab/carved-signage serif evoking chiseled shopfront lettering; body in a warm humanist sans. Capiz lattice (calado fretwork) renders as thin SVG linework dividing sections, never a CSS gradient standing in for it.

STORY: A visitor sees a real Filipino home before any copy loads, feels "this builder understands my house," reads the financing offer as the door already open to them, and calls.

FIRST VIEWPORT: A capiz-shell window grid (actual divided panes, each a crop of the hero photo) fills most of the screen, framed in a hardwood border; carved-serif headline sits on the frame's cream sill, Build-Now-Pay-Later is a lit orange plaque inset into the frame, one wrought-iron call button is the only interactive element above the fold.

FORM: Bahay-na-bato / capiz-shell Filipino ancestral-home world, build candidate chosen directly by the user over the rolled devotional/hymnal assignment; seed: ec659154db59efd5.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
